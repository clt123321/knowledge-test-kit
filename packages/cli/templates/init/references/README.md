# References

Books, papers, official docs, and frontier notes referenced by questions in
this bank. Two accepted formats:

- **JSON** — one file per reference, matching `packages/schema` `ReferenceSchema`:
  ```json
  {
    "id": "sutton-barto-2018",
    "type": "book",
    "title": "Reinforcement Learning: An Introduction",
    "authors": ["Richard S. Sutton", "Andrew G. Barto"],
    "year": 2018,
    "tier": "tier1"
  }
  ```
- **Markdown** — freeform notes; renderable but not schema-checked.
