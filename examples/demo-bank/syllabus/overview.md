# Demo bank syllabus

This demo is intentionally tiny (10 questions across 3 modules). It is used
to smoke-test the kit and to give a new user something to try immediately.

## Modules

- **basics** — version control, HTTP, encoding
- **algorithms** — complexity, sorting, data structures, recursion
- **systems** — caching, CAP theorem, exactly-once, SLO, networking
